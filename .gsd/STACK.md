## Browser APIs Leveraged

- `window.Intl.DateTimeFormat`: Multi-timezone formatting for real-time clocks ticker.
- `HTMLCanvasElement.getContext('2d')`: Custom raster graphics and 60fps game loop rendering.
- `window.requestAnimationFrame`: Frame-rate synchronized physics loop.
- `Element.getBoundingClientRect`: Dynamic canvas responsiveness and viewport bounds detection.
- `Element.setAttribute` & `aria-*`: Keyboard accessibility and screen reader states.
