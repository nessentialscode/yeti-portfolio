## Data Flow

1. **Initial Load:**
   - HTML loaded with default `theme-sage` class.
   - [app.js](file:///c:/Users/jasim/Web%20Project/exp/Giffy/app.js) executes on `DOMContentLoaded`, initializing world clocks, works switcher, theme toggle, drawer handlers, and starting the canvas animation loop.
2. **Interaction & State:**
   - Works tab changes update DOM attributes and trigger an opacity crossfade transition for the featured image and header tint.
   - Theme switch toggles `body.theme-dark` affecting all CSS custom property tokens.
   - Canvas loop runs via `requestAnimationFrame(loop)` calculating delta movements, drawing sprites, and scoring obstacles.
