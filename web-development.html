01 Problem & Context

Traditional dental clinic patients often struggle with opaque pricing, cumbersome phone-only scheduling, and lack of visual clarity regarding dental procedures.

02 Solution & UX Design

Engineered a modern web portal featuring instantaneous digital appointment booking, categorized treatment cards, transparent service information, and direct WhatsApp triage.

03 Architecture & Decisions

  • Next.js framework for fast server-side rendering and search engine indexation.
  • Mobile-first responsive layout tailored for fast smartphone scheduling.
  • Accessible keyboard-navigable forms and WCAG AA contrast compliance.
  • Optimized lightweight asset delivery with Vercel Edge caching.

How to Add New Designs & Web Projects

STANDARD OPERATING PROCEDURE • ZERO BUILD STEP
01

Capture Full-Length Mockups

Capture high-resolution full-page screenshot scrolls of your completed website or design prototype in both viewports:

Mobile: 390px / 430px (e.g. iPhone 15 Pro)
Desktop: 1440px / 1680px (Standard HiDPI)

Tip: Use Chrome DevTools > Run > "Capture full size screenshot" or GoFullPage extension.

02

Save to Assets Directory

Place your exported high-res PNG or WebP files in the projects assets folder following the naming convention:

assets/projects/fullpage/{slug}_mobile_full.png
assets/projects/fullpage/{slug}_desktop_full.png
assets/projects/{slug}_desktop.png (hero crop)
03

Register in WEB_PROJECTS

Open webdev.js and append a new project object to the WEB_PROJECTS array with your metadata, live URL, and GitHub repository.

id, num, title, category, liveUrl, githubUrl, mobileImg, desktopImg, tags, problem, solution, architecture
04

Add Tab & Verify Scroll

Add a matching <button class="webdev-project-tab"> inside web-development.html, reload the page, and verify the full vertical scroll experience down to the footer in both devices.

Checklist: Live link 200 OK • GitHub link active • Smooth scroll verified
